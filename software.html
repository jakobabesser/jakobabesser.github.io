Software & Data

Datasets

Environmental Sound Analysis & Bioacoustics

  • PolyBirdMix Dataset — Large-scale synthetic polyphonic bird call dataset for estimating multiple vocalizing individuals per recording.
  • Urban Sound Monitoring (USM) Dataset — Polyphonic sound event tagging in urban monitoring scenarios.
  • IDMT-TRAFFIC — Audio database for acoustic traffic monitoring.
  • IDMT-FL — Federated learning datasets (DESED-FL and URBAN-FL) for sound event detection.

Music Analysis

  • Weimar Jazz Database — Comprehensive database for jazz research (Jazzomat project).
  • IDMT-SMT-Bass — Audio database for bass transcription and signal processing.
  • IDMT-SMT-Guitar — Audio database for guitar transcription and signal processing.
  • IDMT-SMT-Drums — Audio database for drum transcription and source separation.
  • IDMT-SMT-Audio-Effects — Audio database for automatic effect detection in electric guitar and bass recordings.
  • IDMT-SMT-Bass Synthesis — Digital waveguide model of electric bass guitar with different playing techniques.
  • IDMT-SMT-Bass-Single-Track — Single-track bass recordings for transcription.
  • IDMT-SMT-Chords — Database for automatic chord estimation and music transcription.
  • IDMT-SMT-Chord-Sequences — Dataset for time-dependent harmonic similarity between chord sequences.
  • IDMT-PIANO-MM — Dataset for piano transcription evaluation under microphone mismatch conditions.

Software & Models

  • Walking Bass Transcription using a DNN — Automatic transcription of walking bass lines in jazz recordings (Python code + trained model).
  • bassunet — Bass transcription using a U-Net Model (Python code + trained model).
  • MeloSpySuite & MeloSpyGUI — Command-line tools and GUI for feature extraction and pattern search in symbolic audio datasets.
